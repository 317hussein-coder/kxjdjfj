# تطبيقياي فيديو

مشغّل Android عربي أولي مبني باستخدام AndroidX Media3 / ExoPlayer.

## الميزات الموجودة في هذه النسخة
- اختيار فيديو محلي من الجهاز.
- تشغيل رابط مباشر لملف وسائط متوافق مع Media3.
- تشغيل روابط YouTube عبر المشغّل المضمّن الرسمي (WebView + YouTube embed)، بما فيها روابط watch و youtu.be و shorts و live.
- سرعات تشغيل 0.75× و1× و1.5× و2× للفيديوهات التي يشغّلها ExoPlayer.
- وضع أفقي/ملء الشاشة.
- تحويل النص إلى كلام عربي باستخدام محرك Android TTS المثبت على الجهاز؛ لا يحتاج خادمًا أو مفتاح API، لكن توفر الصوت العربي يعتمد على محرك TTS وبيانات اللغة المثبتة.
- GitHub Actions يبني APK تجريبيًا ويرفعه كـ Artifact.

## بناء APK
افتح تبويب Actions وشغّل **Build TatbiqYai Video APK** أو ادفع تحديثًا إلى الفرع `main`.
بعد نجاح التشغيل افتح الـ workflow run ونزّل artifact باسم `TatbiqYai-Video-debug-apk`.

## حدود مهمة
- رابط صفحة YouTube ليس ملف MP4؛ لا يمكن تمريره إلى ExoPlayer مباشرة. لذلك يستخدم التطبيق المشغّل المضمّن الرسمي ليوتيوب. بعض الفيديوهات قد تمنع التضمين، أو تتطلب تسجيل الدخول/العمر، أو تكون غير متاحة في منطقتك؛ افتحها في تطبيق YouTube عند الحاجة.
- الروابط الخارجية الأخرى يجب أن تكون روابط مباشرة إلى ملفات وسائط، لا صفحات ويب عامة. لا يدعم هذا الإصدار فكّ روابط البث المحمية أو تجاوز قيود المواقع.
- هذه النسخة لا تتضمن حتى الآن نموذج ذكاء اصطناعي فعليًا لتحسين الدقة أو إزالة ضجيج الصوت. لا نعرض مؤثرات عادية على أنها ذكاء اصطناعي. تشغيل تحسينات AI حقيقية يتطلب نموذجًا محليًا مناسبًا أو خادم استدلال موثوقًا، وقد تكون الخدمات المجانية محدودة بحصص وتغيّر شروطها.
- المشروع نسخة عملية أولية، وليس 100 ميزة مكتملة. الميزات تُضاف وتُختبر واحدة تلو الأخرى بدل الادعاء بوجود وظائف غير منفذة.
