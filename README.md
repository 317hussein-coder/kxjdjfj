# تطبيقياي فيديو

مشروع Android أولي لمشغّل فيديو عربي باستخدام AndroidX Media3 / ExoPlayer.

## الميزات الموجودة
- اختيار فيديو محلي من مدير الملفات.
- تشغيل رابط HTTP/HTTPS مباشر لملف فيديو.
- أزرار سرعة 0.75× و1× و1.5× و2×.
- وضع أفقي/ملء الشاشة.
- واجهة عربية داكنة.
- سير عمل GitHub Actions يبني APK تجريبيًا ويرفعه كـ Artifact.

## البناء
افتح المستودع في GitHub ثم تبويب **Actions** وشغّل **Build TatbiqYai Video APK**، أو ادفع أي تحديث إلى الفرع `main`.
بعد نجاح البناء افتح تشغيل الـ workflow ونزّل artifact باسم `TatbiqYai-Video-debug-apk`.

## حدود النسخة الحالية
هذه نسخة أولية وليست مشغّلًا شاملًا لكل الصيغ. نجاح تشغيل بعض الروابط يعتمد على كون الرابط مباشرًا ومتوافقًا مع Media3 والجهاز.
