# تطبيقياي فيديو ناتيف — Qt 6 / C++ / libmpv

هذا مجلد مستقل عن نسخة Java/Media3 الموجودة في جذر المستودع. لا يستخدم WebView أو HTML أو Electron. الواجهة مكتوبة بـ Qt Quick/QML، ومنطق التشغيل والربط مع المحرك مكتوب بـ C++ عبر واجهة libmpv.

## البنية

```text

├── README.md

│   └── AndroidManifest.xml

    └── mpv/                  # ينشئه CI؛ لا تضع مكتبات كمبيوتر هنا
        ├── include/mpv/
        └── lib/arm64-v8a/
```

## البناء من الهاتف عبر GitHub Actions

1. افتح تبويب **Actions** في المستودع.
2. اختر **Build Native Qt6 libmpv APK**.
3. اضغط **Run workflow** ثم **Run workflow** مرة أخرى.
4. انتظر انتهاء الوظيفة. لا تعتبر البناء ناجحًا إلا إذا كانت الحالة **Success** وظهر Artifact باسم `TatbiqYai-Native-Qt6-libmpv-arm64`.
5. افتح نتيجة التشغيل ونزّل ملف APK من قسم Artifacts.

Workflow يحاول تجهيز رؤوس libmpv والمكتبات الأصلية لـ arm64-v8a ثم يبني المشروع باستخدام Qt 6 وAndroid NDK. إذا لم تتوفر مكتبة `libmpv.so` المتوقعة، أو لم تتوافق واجهة المكتبة مع المحرك، فسيفشل البناء برسالة واضحة بدل إنشاء APK مضلل.

## ملاحظات تقنية مهمة

- الهدف الأول هو Android arm64-v8a، وهو مناسب لمعظم الهواتف الحديثة. دعم ABI أخرى يحتاج مكتبات libmpv منفصلة لكل معمارية.
- لا يمكن ضمان فك ترميز عتادي لكل ملف أو جهاز؛ `hwdec=auto-safe` يطلب من mpv اختيار مسار آمن متاح.
- الترجمات SRT/ASS تعتمد على دعم libass ضمن المكتبات المضمّنة.
- «صفر تأخير» ليس ضمانًا واقعيًا؛ هذا التطبيق يستخدم بحثًا دقيقًا، لكن زمن الاستجابة يتأثر بالترميز ومفاتيح البحث والتخزين والجهاز.
- هذا مشروع أولي تجريبي. يجب فحص سجل Actions واختبار APK على جهاز فعلي قبل اعتباره إصدارًا جاهزًا للاستخدام.
- لا ترفع مفاتيح أو ملفات توقيع خاصة إلى المستودع.
